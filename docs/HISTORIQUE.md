# Site Ballon d'Or 2026 — brief

> Archive : ancien `CLAUDE.md` (jusqu'au 27/09/2026, avant l'audit), gardé tel quel pour l'historique des décisions. Certains passages ne décrivent plus le site actuel : la référence est `CLAUDE.md`.

Site one-page présentant les 10 candidats au Ballon d'Or (saison 3 août 2025 – 19 juillet 2026). Inspiration de mouvement : le site Ciao Energy (carrousel de canettes, zoom au clic).

**Contrainte principale : le site doit rester léger.** Objectif : moins de 400 ko au premier chargement (hors polices), environ 1 Mo supplémentaire par joueur ouvert.

## Stack

Vite + React + Framer Motion. Rien d'autre (pas de librairie de carrousel, pas de framework CSS lourd), sauf GSAP + ScrollTrigger pour la page finale uniquement (demande du 26/09/2026), chargés à la demande (import dynamique, ~45 ko gzip, hors premier chargement ; préchargés à l'ouverture de la page 3). Build statique déployable sur GitHub Pages.

Les vidéos brutes fond vert sont rangées hors du projet, dans `~/videos/` (`/Users/pierrestang/videos/`) : rien de ce qui n'est pas utilisé par le site ne doit se trouver dans `public/`, car tout y est copié dans le site en ligne.

Commandes, lancées depuis `BO2026/` :
```
python3 scripts/excel_vers_json.py controle-stats-ballon-dor.xlsx
python3 scripts/convertir.py ~/videos/<fichier>.mp4 <id-du-joueur>
```
L'`id` doit correspondre au champ `id` de `players.json` (ex : `michael-olise`, `kylian-mbappe`). Chaque joueur pèse ~1,8 Mo de séquence (810×1440, AVIF q70) et ~20 ko de poster (800 px, AVIF q55). Choix validé le 24/09/2026 : la qualité prime sur l'objectif initial d'~1 Mo (WebP 960 px q70 jugé trop flou).

Les vidéos IA ont du flou de bougé de profil (3 à 4× moins net que de face) : `convertir.py` prend pour chaque position la voisine la plus nette (±1 image) et accentue la netteté en proportion du flou. La photo studio de face (`~/joueurs/detoures`, compétence detourage-joueurs) est calée sur l'image 000 → `face.avif` (~50 ko) et sert aussi de poster. Pas de photo de dos : le raccord avec la vidéo dédouble nom et numéro. Si la pose de la photo diffère trop de la vidéo (recouvrement < 0,80), le script garde l'image 000, sauf avec `--forcer-photo` : c'est le cas de Messi (déjà fait le 24/09/2026, recouvrement 0,73 ; léger changement de pose au fondu vers la photo, accepté le 27/09/2026 au profit de la netteté).

Tous les chemins du JSON commencent par `assets/` : les préfixer avec `import.meta.env.BASE_URL` pour qu'ils fonctionnent aussi sur GitHub Pages.

Mouvement réduit : le nom change sans animation. En bas, la flèche blanche clignotante (`.intro-down`, partagée avec le bas de la page 2) apparaît une fois la pièce en place.

## Intro ↔ sélection : une seule scène (27/09/2026)

L'intro et la sélection sont un seul composant (`Carousel.jsx`) : l'intro est l'état 0 d'une progression (`progress`), la sélection l'état 1. Pas de défilement de page ni de scroll-snap (choix du 27/09/2026 : transition déclenchée par un geste plutôt que pilotée par le scroll) : un geste joue la transition (`goTo`, `TRANSITION` : 1,6 s pour le trajet complet), dans un sens ou dans l'autre, interruptible (un geste inverse la rembobine depuis là où elle en est) ; jamais bloquée à mi-chemin. Vers la sélection : clic sur le chevron, Entrée, ↓, Espace, molette vers le bas, glisser vers le haut (pas pendant le chargement). Vers l'intro : ↑, molette vers le haut, glisser vers le bas. Molette : un geste = une action (inertie ignorée, nouveau geste après 150 ms de calme). Timeline : chevron (0 → 0,15) ; « BALLON D'OR 2026 » dissous lettre par lettre des extrémités vers le centre, décalage vers l'extérieur et flou (0 → 0,25) ; pièce + halo + nom (un seul bloc, `.stage-hero`) de 48vmin au centre de l'écran à la taille et à la place exactes de la pièce de la sélection (0,1 → 0,7 ; échelle calculée d'après `useLayout`, pas de 25vmin fixe : aucun relais, aucun saut) ; le titre (« DUEL », ex-« FAITES VOS JEUX ! ») lettre par lettre de gauche à droite, montée de 30 px et flou (0,35 → 0,7) ; description (0,55 → 0,8) ; emplacements (0,65 → 0,9, échelle 0,9 → 1) ; flèches et chevron du duel (0,85 → 1). La sélection ne répond qu'au-delà de 0,97 (`.is-live`). Joueur : posée sur l'intro, la pièce tourne et change de nominé toutes les 2 s ; le carrousel s'ouvre sur le joueur affiché ; en revenant de la sélection, l'intro montre d'abord le joueur choisi (pleine même s'il est placé ou si le duel est prêt), puis reprend le défilement 2 s plus tard (27/09/2026). Depuis la sélection posée et le duel prêt, un geste vers le bas ouvre la page du duel ; au retour, la sélection est affichée d'emblée (sans chargement). Mouvement réduit : fondu enchaîné entre les deux états (0,4 s, sans déplacement ni flou), pas de rotation, pas de flottement, le trophée s'efface en simple fondu.

## Principe : le duel

Le site compare toujours **deux joueurs** (choix validé le 24/09/2026 : remplace l'ancienne expérience à un joueur). L'écran est coupé en deux, le côté droit est le miroir du gauche. Un même joueur ne peut pas être des deux côtés (la rotation saute le joueur affiché en face).
